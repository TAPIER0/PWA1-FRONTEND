# PWA1-FRONTEND
En este repositorio se subiran los archivos creados de Frontend para el Proyecto de Aula y PGC para UDEC 2026-II

FrontEnd (TEA Nivel 1)
Usando HTML, JavaScript, CSS para una plataforma de apoyo pedagógico orientada a estudiantes diagnosticados con Autismo Nivel 1 (Trastorno del Espectro Autista).

El sistema implementa interfaces accesibles con perfiles sensoriales personalizables, estructuración de rutinas predecibles y seguimiento pedagógico para docentes, acudientes y estudiantes.
